WHAT THIS IS. Ten worlds and three driver attacks, each a throwaway clone of
this branch checked out at

with one or two lines APPENDED and COMMITTED, so every row is measured on a
CLEAN tree by the gate run from inside that clone. `work tree clean: 0 entries`
is printed for each. The subject commit is this commit's tree minus this file,
`RUN-EVIDENCE-AUTHORITATIVE-ROUND27.txt`, the regenerated figures of the blocks
that counting these two files moves, and the lines of §7.28 naming them.

THE SINK EACH WORLD IS GIVEN is the REAL authoritative run's own sink with its
`RUN_HEAD` line retargeted to that world's commit — which is exactly what
someone who can write a file would do, and the point of every red row is that
retargeting a sink does not put a ROW into it. The real sink is 231 lines,
sha256 92a9551d3fd42991db744ca901cc27a0f28b2278ed178e5f3ff75520ff94c212.

WHAT EACH ROW MEASURES.
  * world 1 is the control: a fabricated figure no case required.
  * worlds 2, 3 and 4 are `R27-F1`, the three doors round 27 closed: a
    `RAISE NOTICE` in a fixture the run APPLIES, an `echo` in the driver the
    run RUNS, and a `RAISE NOTICE` in the applied pack DDL. Each one PRINTS the
    figure in the run's own voice, which round 26's rule accepted.
  * worlds 5 and 6 are `R27-F2`: a figure a case really does require, asserted
    of another case, and asserted of no case at all.
  * world 7 is the PASS direction, and it is the row that makes the rest
    evidence rather than a gate that reds everything.
  * worlds 9 and 10 are the coordinator's `C27-S1`: the same fabricated figure
    written with `U+00B4` and with a bare `U+0301` between the `=` and the
    value, which NFKC leaves as a combining mark the old class did not delete.
    Each one is now a candidate and reds, and the finding prints the spelling
    as written beside the canonical one.
  * world 8 is a sink carrying this commit's own `RUN_HEAD` and not one row.
  * attack A sets `P11_RUN_CAPTURE` in the driver's environment.
  * attack B commits the `RAISE NOTICE` into the applied pack DDL, which is
    what the round's new byte pins are about.
  * attack C hands the driver a `TMPDIR` named for the figure, which is how the
    first challenger drove round 26's rule to `EXIT_SCRIPT 0`.
