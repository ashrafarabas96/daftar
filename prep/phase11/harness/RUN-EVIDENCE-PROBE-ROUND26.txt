P11 — ROUND 26'S OWN SHAPES, DRIVEN END TO END ON COMMITTED CLONES
==================================================================

WHAT THIS IS. Eleven worlds, each a throwaway clone of this branch checked out
at

    d7dcb536670d3cc4ed3ba0ca87d9aeff641b863a

with one or two lines APPENDED and COMMITTED, so every row is measured on a
CLEAN tree by the gate run from inside that clone. `work tree clean: 0 entries`
is printed for each. The subject commit is this commit's tree minus this file,
`RUN-EVIDENCE-AUTHORITATIVE-ROUND26.txt`, the regenerated figures of the two
blocks that counting these two files moves, and the lines of §7.27 naming them.

THE CAPTURE EACH WORLD IS GIVEN is the REAL authoritative run's output with its
`RUN_HEAD` line retargeted to that world's own commit — which is exactly what
someone who can write a capture would do, and the point of every red row is
that retargeting a capture does not put a figure INTO it. The real capture is
1327 lines, sha256
9cdc73eb6e29803443ecb120fda8088822721d70befe14dda3467165e0fdc8b7.

WHAT EACH ROW MEASURES. Worlds 1–7 are `R26-F1`: the same fabricated figure
written bare, then with a space on each side of the `=`, a space before the
value, a tab, U+00A0, U+202F, and the `&nbsp;` character reference. Worlds 8–10
are `R26-S1` / `C26-F1`: the figure plus a `#` comment in `proofs.py` which the
run DOES execute, plus a committed `.py` nothing imports, plus a `--` comment
in `world.sql` which the run DOES apply — the three shapes the old suffix
whitelist admitted. World 11 is the PASS direction: a figure the run genuinely
PRINTED, written padded in the document, which is one figure under `the same
spelling on both sides`.

HOW TO READ IT. Ten reds, each naming the WRITTEN spelling beside the figure it
normalises to, and one pass. `1 not emitted` and `scan rc=1` is the gate
refusing; `0 not emitted` and `rc=0` is the gate accepting a figure the run
printed. Before this round every one of worlds 2–10 was GREEN at
`EXIT_SCRIPT 0` with the fabricated figure in a document.
