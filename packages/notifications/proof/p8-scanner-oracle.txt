# The scanner ORACLE corpus. ROUND 32, answering the twenty-second challenge's
# D-1 and D-2 (both P1).
#
# `p8-scanner-corpus.txt` compares the two scanners with EACH OTHER. That is a
# necessary measurement and it is not a sufficient one, and the twenty-second
# round proved it by building an input on which the two agree and the SERVER
# does not: a dollar-quote tag carrying a supplementary-plane character, which
# PostgreSQL accepts and neither scanner recognised, so a case hid its own
# WHERE from every law and detached the predicate the row form appends. The
# whole gate stayed FAILED=0.
#
# So this corpus ends the regress somewhere else: in what the SERVER DID.
# Each line is a payload appended to
#
#     UPDATE <bench> SET v = v + 1 <payload>
#
# over a two-row bench. The server's verdict is READ FROM THE ROWS: if one row
# moved, a predicate acted; if both moved, none did. The scanner's verdict is
# whether its `strip` output still shows the keyword. The two must agree, and
# where they do not the arm reds BY NAME. Nothing here reads a second text to
# check the first.
#
# Fields: label <TAB> UTF-8 hex of the payload <TAB> comment. Hex, so that no
# escaping convention of the shell, psql or Python sits between the payload
# this file declares and the bytes the server is given.
