# Two implementations of one language that can drift apart are two languages,
# and a reading that had drifted from the server's own lexing is the defect
# this round answers. So `p8-case-net.py` and `p8.sql_scan` are run over this
# file and their outputs compared byte for byte.
#
# Each data line is `<label><TAB><input as UTF-8 hex><TAB><comment>`, and the
# OUTPUT is hex too. Hex because any readable escaping convention would be a
# third reading of the same text sitting between the two being compared: a
# backslash or a quote would have to mean the same thing to a shell, to
# Python and to psql, and that is the class of assumption this arm exists to
# refuse. Hex has one meaning everywhere.
